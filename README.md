# dsh-whale-catcher · 小鲸鱼抓token

给 DSH Web 装一个小游戏：左下角一枚 `🐟 抓token` 按钮，点开新标签页就是一局。

> 抓到的 token 会加成你身上的数字；撞上比你大的鱼会掉一颗心；白饭回血；鲸元券让你下一钩无视大小。

## 装

需要机器上有 `pnpm`（`dsh plugin` 是调 pnpm 装的；没有的话先 `npm i -g pnpm`）。

```bash
dsh plugin --profile web add dsh-whale-catcher
```

装完刷新页面（HMR 会自己把 bundle 重组合），左下角就有按钮了。
本地开发用 link 安装，改完刷新即可，不用重装：

```bash
dsh plugin --profile web add link:/绝对路径/dsh-whale-catcher
```

卸载：

```bash
dsh plugin --profile web remove dsh-whale-catcher
```

## 玩法

- **抓**：钩爪左右匀速摆，左键 / 空格把它甩出去，勾到什么算什么。
- **数字**：鱼身上是它的 token 数。抓到 **不大于** 你的鱼 → 数字累加（10 + 6 = 16）。
- **掉血**：抓到 **比你大** 的鱼 → 掉一颗心，数字不变。场上只会同时有 3~4 条比你大的鱼。
- **白饭**：回一颗心。掉血后每 10 秒浮上来一碗，吃掉了重新倒数。
- **鲸元券**：下一钩无视大小，直接吃下。
- **两分钟**一局，三颗心用完就结束。分数记在本机浏览器里。

## 它做了什么

| 路由 | 作用 |
| --- | --- |
| `GET /dsh-whale-catcher` | 302 到游戏页 |
| `GET /dsh-whale-catcher/game.html` | 游戏本体（单文件，无外部依赖） |
| `GET /dsh-whale-catcher/entry.js` | 宿主页面里那枚按钮 |

外加一次首页注入（Web 走 `tapIndex`，桌面端走 `webserver/index-inject` 结构化行）。
插件不读凭据、不写文件、不发网络请求：整套东西就是"把一个 HTML 发出去"。

## 兼容

- 需要宿主提供 `webServer` 服务（DSH 0.2.x 及以上的 web profile 都有）。
- 没有 `dsh.bundle.patch` 之外的依赖，也没有 `peerDependencies`，不会把宿主核心包卷进来。
- 游戏分数存在浏览器的 localStorage 里，清缓存就没了，不上传。
